# VerisqAI

AI-Powered Third Party Risk Management (TPRM) Platform

## Overview

VerisqAI is a full-stack web application built to streamline Third Party Risk Management workflows through vendor assessments, questionnaire automation, AI-powered analysis, risk scoring, findings generation, and recommendations.

This repository contains the development version of the project.

---

## Important

The **main branch** contains the local/development version of the application.

The latest deployed and production-ready version is available in the:

```text

```

branch.
